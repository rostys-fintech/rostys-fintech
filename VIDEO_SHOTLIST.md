# Video Shot List

## Pitch video — target ~2:10

1. **0:00–0:05** — clean title/hero: Liquidity Clock + tagline.
2. **0:05–0:38** — voiceover on problem while hero remains visible.
3. **0:38–0:57** — founder insight; optional small face-cam, otherwise clean product visual.
4. **0:57–1:28** — show `10:00 / -07:00 / 17:00`, route table and recommendation.
5. **1:28–1:50** — show **Run Liquidity Rescue** + animated rescue result; mention background Solana verification.
6. **1:50–2:08** — market wedge / stress-time decision layer.
7. **2:08–2:16** — clean close on logo/tagline: `amount × executability × time`.

## Technical demo — target ~1:45

1. Open permanent URL with **Timing Stress** selected.
2. Show headline clocks: `10:00 / -07:00 / 17:00`.
3. Scroll to route table; pause on Solana Reserve.
4. Show Recommended Action: projected `-07:00 → +14:00`.
5. Click **Run Liquidity Rescue** once.
6. Keep cursor still while loading/progress animation runs.
7. Show completed simulated outcome:
   - `1.50M → 4.65M`
   - `10:00 → 31:00`
   - `-07:00 → +14:00`
8. Show Execution & Verification section.
   - If chain confirmed: briefly show `LIVE VERIFIED`, signature, slot and Explorer.
   - If verification is pending: show the honest pending state and continue; do not retry during the recording.
9. Switch to **Custom Stress** and change Reserve ETA to demonstrate that a late route is rejected.
10. Finish on the updated recommendation/result.

## Recording quality gate

- Use the permanent URL: `https://rostys-fintech.github.io/rostys-fintech/`.
- 1440p preferred; 1080p acceptable.
- Browser zoom 90–100% so the relevant card is visible without frantic scrolling.
- Hide bookmarks bar if it exposes personal information.
- Close unrelated tabs and disable notifications.
- No personal wallet balances, email, messages or private academic material on screen.
- Cursor movements slow and intentional.
- Do not use browser search or developer tools in the final recording.
- Let loading animations finish naturally; cut only genuine dead time.
- Pitch < 3:00.
- Technical demo < 3:00.
- Never describe a synthetic outcome as a real asset transfer.
- Never describe pending verification as confirmed on-chain execution.
