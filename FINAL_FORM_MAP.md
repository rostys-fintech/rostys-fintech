## 1. Product name — READY

**Liquidity Clock**

## 2. Brief product description — READY

Liquidity Clock is a stress-time decision engine for digital-asset treasuries. It compares current executable liquidity with outflow velocity, maps when additional liquidity routes can actually become usable, identifies the first binding timing gap, and tests the fastest sufficient intervention.

## 3. Blockchains / tools integrated — READY

- Solana Devnet / Testnet verification layer
- Solana Web3 browser integration
- Deterministic JavaScript liquidity engine
- GitHub Pages public deployment
- Browser-based responsive UI

Precise wording: the treasury scenario is synthetic. Solana is used as a verification layer only when a public test-cluster transaction actually confirms.
